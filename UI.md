# UI.md

## Назначение

UI MVP должен быть простым, понятным и ориентированным на ежедневную работу команды с задачами.

## UI-стек

- Tailwind CSS
- shadcn/ui
- FullCalendar для календарного представления задач

## Общие принципы интерфейса

- Интерфейс должен быть минималистичным и практичным.
- В первую очередь показывать задачи, дедлайны, статусы и исполнителей.
- Не добавлять AI-блоки, AI-кнопки, AI-чаты или AI-подсказки в пользовательский интерфейс.
- Компоненты должны быть небольшими и переиспользуемыми.
- Состояния загрузки, пустые состояния и ошибки должны быть понятны пользователю.

## Навигация

Основная навигация приложения:

- Дашборд
- Задачи
- Доска
- Календарь
- Проекты
- Команда
- Настройки

## Задачи

Карточка или строка задачи должна показывать:

- название
- статус
- приоритет
- исполнителя
- дедлайн
- проект, если задача связана с проектом

## Доска

Доска строится по статусам:

- новая
- в работе
- на проверке
- готово

Каждая колонка показывает задачи соответствующего статуса.

## Календарь

- Календарь должен отображать задачи по `due_date`.
- Событие календаря должно вести к задаче.
- Задачи без `due_date` не должны отображаться в календаре.

## Формы

Формы должны быть короткими и понятными.

Минимальная форма задачи:

- название
- описание
- проект
- исполнитель
- статус
- приоритет
- дедлайн

## Визуальные статусы

Статусы задач должны визуально отличаться друг от друга, но не должны перегружать интерфейс.

Приоритет `срочно` должен быть наиболее заметным.
