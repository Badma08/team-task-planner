# FEATURES.md

## MVP-функции

### 1. Дашборд

- Сводка по задачам пользователя.
- Ближайшие дедлайны.
- Количество задач по статусам.
- Быстрые ссылки на задачи, проекты и календарь.

### 2. Задачи

- Создание задачи.
- Просмотр списка задач.
- Редактирование названия, описания, статуса, приоритета и дедлайна.
- Назначение исполнителя.
- Фильтрация по статусу, приоритету, проекту и исполнителю.

### 3. Доска

- Колонки по статусам задач:
  - новая
  - в работе
  - на проверке
  - готово
- Перемещение задач между статусами.
- Быстрый просмотр карточки задачи.

### 4. Календарь

- Отображение задач по полю `due_date`.
- Переход из события календаря в задачу.
- Фильтрация календаря по проекту и исполнителю.

### 5. Проекты

- Создание проекта внутри команды.
- Список проектов команды.
- Страница проекта со связанными задачами.
- Архивация проекта может быть добавлена позже, но не обязательна для первого MVP.

### 6. Команда

- Просмотр участников команды.
- Отображение роли участника.
- Назначение задач участникам команды.

### 7. Комментарии

- Комментарии внутри задачи.
- Отображение автора и времени создания комментария.
- Комментарии всегда относятся к конкретной задаче.

### 8. Настройки

- Базовые настройки профиля.
- Базовые настройки команды.

## Не входит в MVP

- AI-ассистент в интерфейсе.
- Автоматическая генерация задач нейросетью.
- Интеграции с Slack, Telegram, Google Calendar или Jira.
- Тайм-трекинг.
- Финансовые функции.
- Продвинутая аналитика и отчеты.
