# AGENTS.md

Ты работаешь над MVP командного планировщика задач.

## Стек проекта

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase
- PostgreSQL
- FullCalendar

## Цель продукта

Создать веб-приложение для команды, где можно создавать проекты, задачи, назначать исполнителей, ставить дедлайны, менять статусы, оставлять комментарии и смотреть задачи в календаре.

## Важное ограничение

В продукте пока НЕ должно быть AI-функций. Нейросети используются только для разработки.

## Основные разделы

- Дашборд
- Задачи
- Доска
- Календарь
- Проекты
- Команда
- Настройки

## Основные сущности

- пользователь
- команда
- участник команды
- проект
- задача
- комментарий

## Статусы задач

- новая
- в работе
- на проверке
- готово

## Приоритеты задач

- низкий
- средний
- высокий
- срочно

## Главные правила разработки

1. Работай маленькими этапами.
2. Не переписывай весь проект без необходимости.
3. Не добавляй функции, которых нет в MVP.
4. Не подключай базу данных, пока задача явно не просит это сделать.
5. Не добавляй AI-функции в пользовательский интерфейс.
6. После каждого изменения пиши, какие файлы изменены.
7. После каждого изменения пиши, как проверить результат.
8. Если возникает ошибка, сначала объясни причину, потом предложи минимальное исправление.
9. Все будущие командные данные должны быть связаны с `team_id`.
10. Календарь должен отображать задачи по полю `due_date`.
